Mimo 桌宠（Windows 桌面应用）
================================

一个会自己在桌面上走动、还会回应你的小宠物。
直接双击 MimoPet.exe 就能运行，不需要安装 Python 或其他依赖。

【它平时自己做什么】
  · 安静地"玩手机"或"干活中"，每种状态保持约 30 秒
  · 然后随机挑一个方向、随机走一段距离（约 220~620 像素），
    始终保持在同一条水平线上，不会满屏乱跑
  · 走完再回到"玩手机 / 干活中"，如此循环
  · 想让它开机自动启动：按 Win+R 输入 shell:startup，
    把 MimoPet.exe 的快捷方式放进去即可

【怎么和它互动】
  · 单击它            → 投喂：吃两口（吃饭中动画）
  · 双击它            → 抚摸：高兴地跳两下（跳跃动画）
  · 鼠标碰到它不点击   → 打招呼：挥手
  · 20~30 秒内连续挪它 3 次以上 → 它会沮丧
  · 左键按住拖动       → 把它拎到桌面任意位置
  · 右键点它           → 菜单：投喂 / 抚摸 / 暂停 / 放大 / 缩小 / 退出

【动作速度】
  站立类动作、打招呼、吃饭等都做了放慢处理，走动速度也和脚步节奏对齐，
  所以不会出现"滑步"或"太快不自然"的感觉。

【动作用到的 9 套动画】
  待机 / 向右跑 / 向左跑 / 挥手 / 跳跃 / 沮丧 / 玩手机 / 干活中 / 吃饭中

【怎么退出】
  右键点它 → 退出。
  如果它跑到屏幕外找不到了，双击同目录的"停止桌宠.bat"强制关闭。

【说明】
  · 支持 Windows 10 / 11（64 位）。
  · 始终保持在最上层，不抢键盘焦点，不占任务栏。
  · 运行日志： %LOCALAPPDATA%\MimoPet\mimo_pet.log
